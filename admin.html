Agility Sync Engine

Bulk import from Agility REPORT to CRM pipeline

How it works

  • 1. Scans the Agility REPORT sheet for rows without a Sync_Status
  • 2. Extracts OVR / OVK numbers from description field
  • 3. Matches against existing ORDERS records, or creates new customer shells
  • 4. Maps products (e.g. FTTR-20-10 → Vuma Reach 20Mbps/10Mbps) and splits names
  • 5. Inserts into CUSTOMERS, ORDERS, PAYMENTS, and ACTIVATIONS

This operation processes all unsynced rows in bulk. Ensure the Agility REPORT data is up to date before running.
